# NGG Enquiry Letters

เว็บสร้างจดหมายขอบคุณลูกค้า NGG Timepieces ฉบับไทย/อังกฤษ ขนาด 600 × 814 px

**ใช้งาน:** https://nggtimepieces.github.io/enquiry-letters/

ใช้ฟรี ไม่ต้องมีบัญชี Claude · ข้อมูลลูกค้าประมวลผลในเบราว์เซอร์เท่านั้น ไม่ถูกเก็บไว้ที่ไหน

## เพิ่มรูปนาฬิกาเข้าคลัง

- วิธีง่าย: ในหน้าเว็บ ส่วน "คลังรูปนาฬิกา" → ลากรูปมาวาง → ใส่รหัส/รุ่น → **เตรียมไฟล์**
  ระบบจะตัดขอบและตั้งชื่อไฟล์ให้ แล้วกดลิงก์ "เปิดหน้าอัปโหลด" → ลากไฟล์นั้นขึ้นไป → **Commit changes**
- หรืออัปโหลดเองเข้าโฟลเดอร์ `watches/` โดยตั้งชื่อไฟล์เป็น `รหัส_รุ่น.png`
  เช่น `M126711CHNR-0002_GMT-MASTER II.png` (ไม่ใส่รุ่นก็ได้: `M126711CHNR-0002.png`)
- ลบ/เปลี่ยนรูป: ลบหรืออัปโหลดทับไฟล์ในโฟลเดอร์ `watches/`
- หลังอัปโหลด รอ ~1 นาทีแล้วรีโหลดหน้าเว็บ

## เพิ่ม/แก้รายชื่อพนักงานขาย

เปิด `index.html` → ไอคอนดินสอ (Edit) → ค้นหา `const SALESPEOPLE` →
เพิ่มบรรทัดตามรูปแบบ `{en:"Anurak Pawong (Parewa)", th:"อนุรักษ์ ปาวงค์ (แพร)"},` → **Commit changes**

## หมายเหตุ

- อ่านภาพหน้าจอด้วย OCR ในเบราว์เซอร์ ชื่อภาษาไทยอาจอ่านผิดบางตัว ตรวจก่อนส่งทุกครั้ง
- repo นี้เป็น Public มีแค่หน้าเว็บและรูปนาฬิกา ไม่มีข้อมูลลูกค้า
- `watches/list.json` เป็นสำรอง ใช้เฉพาะตอนที่ GitHub API ใช้ไม่ได้ ปกติไม่ต้องแก้
